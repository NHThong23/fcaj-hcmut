### Kết quả đạt được sau tuần 2

- Hiểu rõ cách AWS tổ chức mạng ảo qua VPC, bao gồm subnet, route table và internet gateway
- Thành thạo thao tác khởi tạo, cấu hình và kết nối vào EC2 instance
- Tạo được S3 Bucket, RDS instance và DynamoDB table, nắm được sự khác biệt giữa SQL và NoSQL trên AWS
- Sử dụng thành thạo AWS CLI để quản lý tài nguyên từ dòng lệnh, bước đầu làm quen với Infrastructure as Code
